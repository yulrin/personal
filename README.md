# Knit Hamster Electron V0.2

Windows desktop hamster time tracker prototype.

## Run

Double-click:

```bat
run_knit_hamster_electron.bat
```

If Electron is not found, run this once in this folder:

```bat
npm install
```

Then run the `.bat` file again.

## Included

- Transparent always-on-top hamster window
- Drag the hamster window by the character area
- Click the bottom status pill to open the dashboard
- Current active app tracking
- App-name based automatic yarn colors
- One-minute inactivity sleep mode
- Knitting animation with moving needles, live yarn loops, and growing colored fabric
- Local-only daily data in `knit_hamster_data.json`

Input text is not stored. The app records only app names, activity time, and yarn colors.
